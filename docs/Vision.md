# 產品願景

## 1. 願景

讓方糖民宿以這台營運電腦為本地 AI 中樞，持續整合 PMS 訂單、住客需求、採購、工作通知與財務資料。經營者可透過手機 LINE 與 AI 溝通，快速回答「今天有哪些住客、何時入住與用餐、有哪些飲食禁忌、需要採購什麼、收入從哪裡來、成本花在哪裡、現金是否安全，以及下一步該注意什麼」。

AI CFO 是此營運 Agent 的財務核心，不取代會計師，也不取代 PMS。系統優先以唯讀方式取得 PMS 資料，建立可追溯事件，再驅動通知、工作流程及財務分析。

## 2. 問題陳述

現有資料若分散在各月份工作表，會造成分類不一致、重複維護、年度彙總困難，以及 AI 難以建立可信分析。設備採購、貸款本金與日常費用若混在一起，也會扭曲單月損益。

V1 因此優先建立：

- 單一交易資料表及一致科目。
- 收入、營運費用、融資現金流的清楚分離。
- 自動月損益、現金流及年度彙總。
- 可追溯、具證據的 AI 經營摘要。

## 3. 目標使用者

### 主要使用者

方糖民宿經營者，負責日常記帳、月結、查看 Dashboard 與採取改善行動。

### 次要使用者

- 內部協作者：協助輸入或核對交易。
- 會計人員：接收經核對的會計匯出資料。
- 未來系統維護者：依本規格延伸 Excel、Web、API 與 AI 功能。
- 工作群組成員：透過 LINE 接收新訂單、入住、用餐與特殊需求提醒。

## 4. 成功樣貌

V1 上線後，使用者應能：

1. 在唯一輸入區新增或匯入 2026 年交易。
2. 在月結後查看月損益、現金收支及年度累計。
3. 追蹤收入來源以及人事、房務、食材等成本占比。
4. 取得附有數據依據、信心標示與行動建議的 AI 摘要。
5. 匯出可供會計人員整理的交易明細與彙總報表。

最終版本應能：

6. 由本地 Agent 定時登入無 API 的 PMS，以唯讀瀏覽器自動化取得新訂單及狀態變更。
7. 將入住／退房、用餐時間、飲食禁忌與備註轉成結構化資料及工作提醒。
8. 透過 LINE Official Account 接收管理者指令及採購紀錄，並向授權群組推送通知。
9. 將訂單付款事件與採購支出送入 AI CFO，不重複認列收入或現金。

## 5. 非目標

V1 不包含：

- 正式複式簿記總帳與法定稅務申報。
- V1 不包含 PMS 網頁自動化；此功能列入營運 Agent 階段。
- ADR、RevPAR、入住率的正式營運判斷。
- 固定資產、折舊、保固及維修管理。
- 庫存、採購單、房務排程與住客 CRM。
- AI 自動變更交易或代替經營者核准付款。

## 6. 產品原則

- **先可信，再智慧**：缺資料時明確說明，不補造結論。
- **輸入一次，多處使用**：同一交易驅動所有報表。
- **分類可治理**：科目可新增，但大類與報表映射須受控。
- **損益不等於現金**：獲利與現金流必須分開呈現。
- **保留可追溯性**：每個指標能回到交易明細。
- **漸進擴充**：V1 的資料結構需支援 Phase 2 與 PMS 整合。
- **唯讀優先**：PMS Agent 預設不得修改訂單、價格、庫存、付款或住客資料。
- **人類核准重要行動**：退款、取消、發送住客訊息、群組廣播及財務更正須依權限核准。
- **最少揭露**：LINE 群組通知只包含工作所需資料，不發送完整身分證件、付款資訊或敏感個資。

## 7. 成功指標

- 月結後可在 10 分鐘內產生完整管理報表。
- 100% 報表金額可回溯到交易。
- 必填欄位完整率達 98% 以上。
- 未分類或「其他」支出占比逐月下降；目標門檻待確認。
- AI 摘要中的數字與報表一致率為 100%。
- 使用者能辨識並處理每月前三大成本異常。

## 8. 已知假設與待確認

- `ASM-001`：V1 單一營運主體為方糖民宿。
- `ASM-002`：幣別以 TWD 為主，暫不處理匯率。
- `ASM-003`：交易以含稅實付／實收金額輸入，稅額拆分規則待會計確認。
- `TBC-001`：會計匯出的必要欄位與會計軟體格式。
- `TBC-002`：期初現金及各帳戶 2026-01-01 餘額。
- `TBC-003`：早餐人次與食材報廢資料是否能固定紀錄。
- `TBC-004`：貸款本金、利息及每期扣款明細。
- `TBC-005`：PMS 網址、登入方式、二階段驗證、訂單列表與訂單詳情畫面。
- `TBC-006`：LINE 工作群組、可接收通知的角色及敏感資料顯示範圍。
- `TBC-007`：新訂單、取消、入住、用餐與飲食禁忌的通知時機。
- `ASM-004`：經營者目前使用 ChatGPT Plus，手機入口採私人 GPT + Actions。
- `ASM-005`：OwlTing OwlNest 為 PMS；本案尚未取得可用 API 文件。
- `ASM-006`：民宿 Mac 每日開機，可作為未來本機 Agent 主機。
- `TBC-008`：OwlNest 自動化存取許可、匯出能力及登入限制。
- `TBC-009`：LINE Messaging API Channel、測試群組與通知矩陣。
- `TBC-010`：HomeKit 設備、Shortcut 及高風險設備安全條件。
