# Dashboard Design

## 1. 設計目標

Dashboard 應讓經營者在一個畫面回答：

1. 這個月收入與管理淨利多少？
2. 與上月及年度累計相比如何？
3. 成本主要花在哪裡？
4. 現金流是否安全？
5. 哪些問題需要立即處理？

## 2. 篩選器

- 期間：本月、上月、年度累計、自訂期間
- 比較基準：上月、近 3 月平均、近 6 月平均
- 收入來源
- 房號（僅限有可靠房號歸屬的交易）
- 報表狀態：即時、已月結

## 3. 首頁資訊架構

### 第一列：核心 KPI

- 本月淨營收
- 本月管理淨利
- 管理淨利率
- 本月淨現金變動

每張卡片顯示：

- 本期數值
- 與比較期差額及百分比
- 資料完整性狀態
- 點擊下鑽

### 第二列：趨勢

- 12 個月收入、營運費用與管理淨利折線／組合圖
- 12 個月淨現金變動柱狀圖

未來月份使用空白視覺，不以 0 製造下降趨勢。

### 第三列：結構

- 收入來源占比
- 成本大類占比
- 前五大支出科目

若項目過多，優先使用排序橫條圖，避免難以閱讀的圓餅圖。

### 第四列：管理警示

- 待分類交易
- 疑似重複
- 「其他」占比過高
- 食材／房務成本異常
- 現金餘額不完整
- 月份尚未關帳

### 第五列：AI 摘要

顯示：

- 三句經營摘要
- 三項主要變動
- 最多三項建議行動
- 信心等級與資料限制

## 4. KPI 定義

| KPI | 公式 | V1 |
|---|---|---|
| 淨營收 | 收入－退款－折讓 | 是 |
| 管理淨利 | 淨營收－V1 費用 | 是 |
| 管理淨利率 | 管理淨利 ÷ 淨營收 | 是 |
| 淨現金變動 | 流入－流出，排除內部轉帳重複影響 | 是 |
| 食材成本率 | 食材費用 ÷ 淨營收 | 是 |
| 房務成本率 | 房務費用 ÷ 淨營收 | 是 |
| 人事成本率 | 人事費用 ÷ 淨營收 | 是 |
| Booking 收入占比 | Booking 淨收入 ÷ 全部淨營收 | 是 |
| ADR | 客房收入 ÷ 已售房晚 | PMS 後 |
| 入住率 | 已售房晚 ÷ 可售房晚 | PMS 後 |
| RevPAR | 客房收入 ÷ 可售房晚 | PMS 後 |

## 5. 指標狀態

- 綠色：在已確認目標內。
- 黃色：接近門檻或資料不完整。
- 紅色：超過已確認風險門檻。
- 灰色：尚無資料或不適用。

在門檻未經使用者確認前，不應使用紅綠判斷，只顯示趨勢及「基準待設定」。

## 6. 下鑽

每個 KPI 與圖表均應可下鑽至：

```text
KPI → 大類 → 科目 → 交易明細
```

交易明細至少顯示日期、科目、金額、帳戶、來源、對象、備註及匯入批次。

## 7. 月損益頁

- 本月與上月並排比較。
- 各費用顯示金額、占比、差額及差異率。
- 提供年度累計。
- 不將貸款本金列入費用。
- 待資產化支出以醒目註記排除或暫列。

## 8. 現金流頁

- 期初現金
- 營運流入／流出
- 融資流入／本金償還／利息
- 投資現金流（Phase 2）
- 淨變動與期末現金
- 各資金帳戶餘額

未提供期初餘額時，只顯示期間變動並附警示。

## 9. 年度頁

以 1 至 12 月呈現：

- 淨營收
- 各成本大類
- 管理淨利
- 淨現金變動

需區分：

- 已月結
- 有資料未月結
- 尚未輸入
- 實際為 0

## 10. 響應與可用性

- 金額預設千分位、無小數；明細可顯示兩位。
- 百分比顯示一位小數。
- 色彩不得是唯一狀態提示，需配合文字或圖示。
- 圖表需有資料來源期間與最後更新時間。
- 匯出畫面應保持列印可讀性。
