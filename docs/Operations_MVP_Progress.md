# 方糖民宿營運 MVP 專案進度表

更新日期：2026-08-06

## 1. 專案目標

先完成可立即投入使用的營運模組：手動建立及管理訂單、查看今日入住、完成 Check-in、確認尾款、選擇早餐與餐點，並產生明日及指定期間備料表。

基礎資料只做到目前營運需要；Gmail、OwlTing、LINE、手機 AI 與財務串接分階段加入。

## 2. 狀態定義

| 狀態 | 意義 |
|---|---|
| ✅ 已完成 | 已有可驗收成果 |
| 🟡 待確認 | 需要使用者決定或提供資料 |
| 🔵 可開發 | 規格已足夠，可直接開始 |
| 🛠 開發中 | 已開始製作但尚未通過驗收 |
| ⬜ 待開始 | 依賴前置工作，尚未開始 |
| ⏸ 延後 | 不列入營運 MVP |

## 9. 需要使用者優先確認

| 3 | Gmail 搜尋範圍 | 指定寄件者加專用標籤 |
| 3 | LINE 測試群組 | 先限管理者與核心工作人員 |

## 10. 每週驗收方式

每週只驗收可操作成果，不以文件或程式碼數量判定進度。

1. 開發人員展示完成項目。
2. 使用者用一筆模擬資料操作。
3. 通過驗收條件後才標示 ✅ 已完成。
4. 未通過項目記錄問題、負責人及預定修正時間。
5. 每個 Sprint 完成後建立 Git 版本標籤。
