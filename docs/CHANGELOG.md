# Changelog

本專案遵循語意化版本概念；規格基線以 `0.x` 版本演進。

## [Unreleased]

### Changed

- 確認 4 道餐點為鮭魚、和牛燒飯、班尼迪克蛋、雜菜煲。
- 一般首次、單日住宿預設鮭魚；多日或二訪住客同一天可吃不同餐點。
- 餐點輪替改由接待人員決定，系統只提供歷史、候選與重複警示。
- 備料表改以實際餐點分配彙總，不採全館單一當日餐點。
- 餐點與備料項目改由管理介面新增、修改、停用及版本化，不寫死配方。
- 二訪不做自動辨識，由接待人員在電話或 LINE 訂房時手動標記。

### Added

- 建立完整系統完成待辦清單，依里程碑、責任、依賴及驗收門檻排序。
- 新增指定期間備料與採購預測待辦：即時同步 OwlTing、展開早餐日、區分確認／預估需求並保存版本差異。
- 新增餐點主檔、多日不重複輪替、快速新增與備料映射缺漏規則。
- 新增所有入住完成提前產生備料草稿、18:00 正式版及後續差異通知。
- 新增餐點、備料項目、備料表及版本資料模型。
- 新增入住接待確認流程，整合證件核驗、用餐需求與尾款確認。
- 新增尾款 `presumed_collected`、`confirmed`、`reconciled` 狀態及月結對帳規則。
- 建立 AI 開發交接文件，定義系統角色、工作包、相依、秘密管理與交付門檻。
- 新增 OwlNest 唯讀整合、ChatGPT 手機 Actions、LINE Messaging API、HomeKit Shortcuts、營運資料模型及驗收測試規格。
- 完成 `2026財務報表.xlsx` 的結構、公式、資料品質與匯入可行性評估。
- 新增原始資料分類映射、匯入優先順序及防重策略。
- 完成 2026-06 Excel V2 端到端試轉，建立單一交易表、月損益、現金流、年度摘要、Dashboard、Checks 與 AI 分析資料包。
- 新增成本明細分析頁，可按月份與成本大類查看子科目、供應商、單筆金額及占比，並追溯至單一交易。

### Confirmed

- 早餐時段為 08:00、08:30、09:00、09:30、10:00 或不用餐。
- 目前有 4 道餐點，鮭魚為預設；多日住宿原則上不重複。
- 每日 18:00 產出次日備料表，亦可在所有入住完成時提前產生草稿。
- OwlNest 現場尾款不要求回寫；入住日已到且訂單未取消時先推定已收，接待確認後才正式入帳。
- 證件預設只保存核驗結果，不保存身分證號碼或照片。
- 使用 ChatGPT Plus，以私人 GPT + Actions 作為手機管理介面。
- PMS 為 OwlTing OwlNest；目前不實作，且未取得可用 API 文件。
- 民宿 Mac 每日開機，未來作為本機 Agent 主機。
- LINE Official Account 已建立，後續使用 Messaging API。
- HomeKit 邏輯可依需求調整，但 AI 不直接控制裝置。
- 年繳費用在管理損益按服務期間逐月攤提，付款日全額反映現金流。
- 固定資產由使用者盤點後於 Phase 2 匯入。
- 原始活頁簿包含 2026-01 至 2026-06 六張月報。
- 現有淨值包含貸款／分期現金支出，不能直接視為管理淨利。
